# Base Daily Builds

A small, growing collection of practical [viem](https://viem.sh) snippets for building on [Base](https://base.org). One snippet is added roughly every other day, alternating with a docs update, until the full set of 30 core actions is covered.

## Snippets

- `snippets/01-getBalance.js` — Read a wallet's ETH balance on Base
- `snippets/01-getBalance.js` — Read a wallet's ETH balance on Base
- `snippets/05-estimateGas.js` — Get the latest block number on Base
