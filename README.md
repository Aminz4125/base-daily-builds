# Base Daily Builds

A small, growing collection of practical [viem](https://viem.sh) snippets for building on [Base](https://base.org). Snippets are added incrementally until the full set of 30 core actions is covered.

## Snippets

- `snippets/01-getBalance.js` — Read a wallet's ETH balance on Base
- `snippets/02-getBlockNumber.js` — Get the latest block number on Base
- `snippets/03-createPublicClient.js` — Set up a viem public client for Base
- `snippets/04-createWalletClient.js` — Set up a viem wallet client for signing
- `snippets/05-estimateGas.js` — Estimate gas cost for a transaction
- `snippets/06-sendTransaction.js` — Send a simple ETH transfer on Base
- `snippets/07-getTransactionReceipt.js` — Fetch a transaction receipt by hash
- `snippets/08-waitForTransactionReceipt.js` — Wait until a transaction confirms
- `snippets/10-writeContract.js` — Send a state-changing contract call
- `snippets/09-readContract.js` — Read data from a smart contract
